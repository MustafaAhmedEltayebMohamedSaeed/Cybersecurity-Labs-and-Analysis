# NIST CSF Incident Response & Analysis

## Overview
An analysis of a credential phishing incident involving unauthorized database access and record manipulation. This activity maps security controls, mitigations, and recovery steps directly to the five core functions of the NIST Cybersecurity Framework (CSF).

## NIST CSF Framework Mapping
* **Identify:** Audited access logs and identified compromised intern credentials used for database unauthorized modification.
* **Protect:** Proposed Multi-Factor Authentication (MFA), account lockout policies, updated firewall rules, and an Intrusion Prevention System (IPS).
* **Detect:** Configured Intrusion Detection System (IDS) and firewall logging for active monitoring of incoming traffic.
* **Respond:** Disabled compromised credentials, initiated security awareness re-training, and handled management/regulatory breach reporting.
* **Recover:** Restored database integrity using clean full-backup recovery procedures.

## Concepts & Skills Demonstrated
* NIST Cybersecurity Framework (CSF)
* Incident Response Lifecycle
* Access Control & Authentication Policy (MFA)
* Network Security Controls (IDS/IPS, Firewalls)
* Data Backup & Recovery Operations
